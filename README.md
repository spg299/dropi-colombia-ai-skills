# Dropi Colombia AI Skills

Ecosistema de skills de inteligencia artificial especializadas para gestionar un negocio de dropshipping con Dropi en Colombia.

**Objetivo principal**: Maximizar la utilidad neta sostenible, no la facturación.

## Skills incluidas

- `trend-hunter`: Detección de tendencias emergentes y oportunidades de productos para COD en Colombia.

## Principios

- Nunca inventar datos comerciales o resultados financieros.
- Distinguir siempre estados de pedido: generados, confirmados, despachados, entregados, devueltos.
- No publicar campañas ni comprometer dinero sin autorización explícita.
- Priorizar herramientas gratuitas y de código abierto.
- Cálculos financieros en Python cuando sea necesario.

## Uso

Estas skills están diseñadas para plataformas de agentes de IA que soportan el formato SKILL.md (con frontmatter YAML, evals y triggers).

Más skills se irán añadiendo progresivamente (winning-product-hunter, profit-calculator, etc.).
